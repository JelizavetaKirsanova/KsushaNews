# Ксюша News

Локальный новостной сайт с редактором публикаций.

## Запуск

В папке проекта выполните:

```bash
npm start
```

Затем откройте [http://127.0.0.1:3000](http://127.0.0.1:3000). Не открывайте `index.html` двойным кликом: форма добавления новостей работает только через локальный сервер.

## Как добавить новость

Нажмите `+ Добавить новость` в шапке сайта. Заполните текст и добавьте хотя бы одну фотографию. Первая фотография становится обложкой статьи; остальные появятся в галерее. Можно также прикрепить несколько видео.

## Хранение данных

- Тексты, заголовки, теги и связи с медиа хранятся в SQLite: `data/ksusha-news.db`.
- Загружаемые фотографии и видео сохраняются локально в `uploads/`.
- При первом запуске сайт переносит уже созданные новости в базу автоматически.
